# Password Security and Hash Analysis Using John the Ripper & NetworkWalks Tools

## Overview

As part of my cybersecurity learning journey with **NetworkWalks**, I completed a practical exercise focused on password generation, password cracking, and hash analysis.

The objective was to understand how passwords are represented using cryptographic hashes, how password-cracking tools attempt to recover passwords, and why strong password practices are important for protecting systems and networks.

## Tools and Technologies Used

- **John the Ripper:** Password security auditing and password-cracking tool.
- **NetworkWalks Password Cracker:** Used to explore password-cracking techniques.
- **NetworkWalks Hash Calculator:** Used to generate and analyse password hashes.
- **Kali Linux:** Environment for running cybersecurity tools.
- **Linux Terminal:** Command-line interaction and execution of commands.

## Practical Activities

### 1. Password Generation and Hashing

I explored how passwords can be converted into hash values using the NetworkWalks Hash Calculator.

This exercise helped me understand:
- The concept of password hashing.
- How plaintext passwords are represented as hash values.
- Different hashing algorithms.
- Why systems store password hashes instead of plaintext passwords.
- The importance of using secure password-hashing algorithms.

### 2. Password Cracking Using John the Ripper

I explored John the Ripper to understand how password-cracking tools work.

The exercise involved:
- Preparing password hashes for testing.
- Using John the Ripper to perform password-cracking exercises.
- Understanding dictionary-based password attacks.
- Exploring how wordlists are used to identify weak passwords.
- Observing how password complexity affects password recovery.

### 3. Online Password Cracking Using NetworkWalks

I also used the NetworkWalks Password Cracker to explore password recovery through a web-based tool.

This provided an opportunity to compare a web-based password-cracking tool with a command-line tool such as John the Ripper.

### 4. Hash Analysis

Using the NetworkWalks Hash Calculator, I explored how different hashing algorithms produce hash values from input data.

This reinforced the relationship between passwords, hashing algorithms, and password security.

## Key Concepts Learned

- Password hashing and hash values.
- Dictionary-based password attacks.
- Password strength and complexity.
- Wordlists and password recovery.
- The role of hashing algorithms in authentication.
- The importance of secure password storage.
- Differences between password cracking and hash generation.

## Key Takeaways

This practical exercise improved my understanding of password security and introduced me to tools commonly used in cybersecurity and security auditing.

One important lesson is that a password's security depends not only on its length but also on its unpredictability. Weak and commonly used passwords are more vulnerable to dictionary-based attacks.

I also learned that hashing is a one-way cryptographic process and should not be confused with encryption.

## Ethical Considerations

All practical activities were conducted for educational purposes using test passwords and hashes. Password-cracking techniques should only be performed on systems, accounts, and data for which explicit authorisation has been granted.
